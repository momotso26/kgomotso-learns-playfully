# Kgomotso's Teaching Hub

Build a polished, responsive personal portfolio website for Kgomotso Mashigo, an Aspiring Educator. Feature: Early Childhood Development Certified NQF 4 (ETDP SETA), qualified to teach ages 0–6; play-based learning from birth to Grade 3 with learning-through-play approach; TEFL 120-hour Certified for teaching English as a Foreign Language; Google AI Essentials Certified (Google/Coursera). Include an engaging hero, about section, qualifications, teaching philosophy, strengths/services, and contact section with a clear professional call to action. Use a warm, child-centered, modern design that still feels credible and professional. Add sensible placeholder contact links where details are not provided.
